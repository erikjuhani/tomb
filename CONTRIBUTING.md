# Contributing to Tomb

## Developer Certificate of Origin (DCO)

This project uses the [Developer Certificate of Origin](https://developercertificate.org/) (DCO). By contributing, you certify that you wrote or have the right to submit the code under the project's GPL-3.0 license.

All commits must be signed off:

```bash
git commit -s -m "Your commit message"
```

This adds a `Signed-off-by: Your Name <your@email.com>` line to your commit message. Use your real name (no pseudonyms or anonymous contributions).

If you forget, you can amend your last commit:

```bash
git commit --amend -s
```

## Submitting Changes

1. Fork the repo and create a branch
2. Make your changes
3. Sign off your commits (`git commit -s`)
4. Open a pull request
